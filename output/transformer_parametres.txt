================================================================================
  PARAMÈTRES DU MODÈLE TRANSFORMER v5 — Phase 2
  Générateur intelligent de mots de passe
================================================================================

─── ARCHITECTURE ───────────────────────────────────────────────────────────────

  Type                : Decoder-only Transformer (style GPT/LLaMA)
  Composants clés     : SwiGLU + RMSNorm + SDPA (Flash Attention) + KV-cache
  Paramètres totaux   : 2,675,328 (~10.2 MB en float32)

  Embedding dim       : 192
  Nombre de têtes     : 6          (head_dim = 192/6 = 32)
  Nombre de couches   : 6
  FFN dim (SwiGLU)    : 512
  Max séquence        : 32 tokens
  Dropout             : 0.08
  Weight tying         : Oui (embedding = tête de sortie)
  Init des poids      : Normal(0, 0.02), projections scalées par 1/√(2×N_layers)

─── TOKENIZER ──────────────────────────────────────────────────────────────────

  Type                : Caractère par caractère (char-level)
  Tokens spéciaux     : <PAD> (idx 0), <SOS> (idx 1), <EOS> (idx 2)
  Taille vocabulaire  : 98 tokens (95 caractères + 3 spéciaux)

─── ENTRAÎNEMENT ───────────────────────────────────────────────────────────────

  Device              : Apple MPS (Metal Performance Shaders)
  AMP float16         : Désactivé (instable sur MPS)
  Epochs réalisés     : 24 (early stopping)
  Durée totale        : ~1h55

  Batch size          : 512
  Gradient accum      : 1          (effective batch = 512)
  Optimiseur          : AdamW (betas=0.9, 0.95)
  Learning rate       : 4e-4
  Weight decay        : 0.005
  Gradient clipping   : 0.8
  Label smoothing     : 0.03
  Loss                : CrossEntropyLoss (ignore_index=PAD)

  # LR Schedule — Cosine Warm Restarts
  Warmup steps        : 50
  Cycle length        : 2,000 steps
  Cycle decay         : 0.85       (LR max ×0.85 à chaque restart)
  LR min              : 1% du cycle max

  # Early Stopping
  Val split           : 5%         (18,792 passwords en validation)
  Patience            : 12 epochs
  Min delta           : 0.001

  # Données
  Train               : 375,853 mots de passe → 357,061 train + 18,792 val
  Eval                : 1,999 mots de passe (0% overlap avec train)

─── GÉNÉRATION ─────────────────────────────────────────────────────────────────

  Candidats par temp  : 500,000
  Températures        : [0.7, 0.8, 0.9, 1.0]
  Stale limit         : 5          (arrêt si <0.5% nouveaux × 5 batches)
  KV-cache            : Oui        (~5x speedup vs sans cache)

─── RÉSULTATS ──────────────────────────────────────────────────────────────────

  Total unique généré : 846,798 (union des 4 températures)
  Coverage eval       : 185/1,999 = 9.27%
  Overlap train       : ~10%

  Par température :
    T=0.7  →  coverage 7.50%  (150 matches)
    T=0.8  →  coverage 7.85%  (157 matches)
    T=0.9  →  coverage 6.75%  (135 matches)
    T=1.0  →  coverage 5.55%  (111 matches)

  Meilleur val_loss   : 1.5765 (epoch 16)
  Meilleure val_acc   : 55.75%

─── COMPARAISON AVEC MARKOV ────────────────────────────────────────────────────

  Markov ordre 4      : 130/1,999  = 2.70%  (baseline)
  Transformer v5      : 185/1,999 = 9.27%  (×3.4 vs Markov)
